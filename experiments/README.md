# Experiments

The scripts behind the runs that shaped the reader, kept as a record of how each result was made: the fair comparisons (E1 to E8), the overnight training runs, and the jobs that built and paired the data. Each ran on a maintainer's machine against its caches and settings, so some name sets and models a fresh checkout does not have. New experiments are written as specs for `staffreader experiment` (docs/improving.md) rather than as scripts here.
